# 70 Sonderprojekt – Claude-Einführung auf fremden Betrieben

**Abgrenzung:** Alles in diesem Ordner gehört zum Sonderprojekt „Claude auf anderen landwirtschaftlichen Betrieben einführen“. Es gilt **nicht für meinen eigenen Betrieb**. Regeln, Abläufe, Programme und Betriebsdaten von hier dürfen nicht auf meinen eigenen Betrieb übertragen werden – und umgekehrt. So bleiben die übrigen Ordner frei von widersprüchlichen Angaben.

Alles, was zum Sonderprojekt oder zu einem der betreuten Betriebe entsteht, kommt in diesen Ordner.

## Aufbau

| Ordner | Inhalt |
| --- | --- |
| `Leitfaden/` | Der Leitfaden als Markdown-Abzug, der Fragebogen, der Einrichtungs-Prompt und die beiden Zeichnungen |
| `Betriebe/` | Eine Betriebsakte je betreutem Betrieb (siehe `Betriebe/README.md`) |
| `Archiv/` | Überholte Fassungen, z. B. der erste Leitfaden vom 24.10.2026 |
