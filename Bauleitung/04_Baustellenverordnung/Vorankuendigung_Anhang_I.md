# Vorankündigung nach §2 Abs. 2 Baustellenverordnung (Anhang I)

*An die zuständige Arbeitsschutzbehörde, spätestens 2 Wochen vor Einrichtung der Baustelle. Auf der Baustelle sichtbar aushängen. Viele Bundesländer haben ein Online-Formular – Inhalte sind identisch.*

| Nr. | Angabe | Eintrag |
|---|---|---|
| 1 | Ort der Baustelle (Straße, PLZ, Ort, ggf. Flurstück) | |
| 2 | Name und Anschrift des Bauherrn | |
| 3 | Art des Bauvorhabens | |
| 4 | Name und Anschrift des anstelle des Bauherrn verantwortlichen Dritten | |
| 5 | Name und Anschrift des Koordinators (SiGeKo) | |
| 6 | Voraussichtlicher Beginn und voraussichtliche Dauer der Arbeiten | |
| 7 | Voraussichtliche Höchstzahl der gleichzeitig Beschäftigten | |
| 8 | Voraussichtliche Zahl der Arbeitgeber und Unternehmer ohne Beschäftigte | |
| 9 | Angabe der bereits ausgewählten Arbeitgeber und Unternehmer ohne Beschäftigte | |

**Schwellenwerte (Vorankündigung nötig, wenn):**

- voraussichtlich > 30 Arbeitstage **und** > 20 Beschäftigte gleichzeitig, **oder**
- Umfang > 500 Personentage.
