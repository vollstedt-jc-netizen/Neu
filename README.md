## Mit Claude arbeiten

- **Handy:** Claude-App → Claude Code → Repository `Neu` → einfach schreiben: „Notiere: Tim wegen Termin anrufen“.
- **PC:** Claude im Hauptordner dieses Repositorys starten (nur dann greift die Sperre für 70–79).
- Typische Sätze: „Was steht an?“ · „Was weißt du über Gülle-Fristen?“ · „Eingang leeren“ · „Neues Projekt: …“ · „Wochenrückblick“ · „Prüf das Second Brain“.
